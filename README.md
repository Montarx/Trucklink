# TruckLink

TruckLink is a green-logistics platform for Greece that matches freight with spare capacity on truck routes that carriers are already planning to drive.

> Find freight that fits routes trucks are already planning to drive.

## MVP

- Carrier profile
- Post a truck route
- Post a freight request
- Automatic route matching
- Match score
- Send request / contact
- Simple impact dashboard

## Matching signals

The first matching engine is deterministic and explainable. It scores:

- pickup distance from the planned truck route
- delivery distance from the planned truck route
- pickup / delivery date compatibility
- available weight
- available pallet capacity

No AI is required for the MVP.

## Impact metrics

Successful matches will feed an impact dashboard with estimates for:

- potentially avoidable empty kilometres
- fuel saved
- CO2 emissions avoided
- additional carrier revenue
- loads matched

## Initial market

The pilot is Greece-first, focused on small and medium carriers / independent drivers and SMEs that need freight transportation.
